# HOW - Local Experiences

Sito di esperienze locali a Lecce, interamente in inglese

Sito pubblico attuale: https://how-local-experiences.alessioditondo01.chatgpt.site

## Progetto

HTML, CSS e JavaScript statici, senza build né dipendenze da installare
La cartella da pubblicare è `dist`
La foto della hero è statica

## Vercel

Importare questo progetto da GitHub
Framework Preset: Other
Output Directory: dist
Build Command: vuoto
Install Command: vuoto
La configurazione è inclusa in vercel.json

Documentazione: https://vercel.com/docs/project-configuration/vercel-json

## Anteprima locale

Dalla cartella del progetto eseguire `python3 -m http.server 8000 --directory dist` e aprire http://localhost:8000

## Prenotazioni

Completare `dist/config.js` con il numero WhatsApp HOW e le sessioni reali
Il numero non è ancora stato fornito e il pulsante WhatsApp rimane disattivato
Senza sessioni configurate il calendario raccoglie una data preferita, senza promettere disponibilità
La selezione di una data non conferma né riserva un posto
